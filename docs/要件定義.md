# 要件定義書 — 共有レシピアプリ

**チーム**: teamB  
**作成日**: 2026-06-01

---

## 1. プロジェクト概要

ユーザーがレシピを投稿・共有・検索できる Web アプリケーション。

## 3. 技術スタック

| レイヤー       | 技術                      |
| -------------- | ------------------------- |
| フロントエンド | Next.js + TypeScript      |
| バックエンド   | Python + FastAPI          |
| データベース   | PostgreSQL                |
| ストレージ     | MinIO（S3互換・画像保存） |
| インフラ       | Docker / Docker Compose   |
| CI/CD          | GitHub Actions            |

---

## 4. 非機能要件

- フロントエンドとバックエンドは分離（モノレポ構成）
- コンテナ環境（Docker）で動作すること
- サーバーサイドは JS/TS 以外（Python + FastAPI）
- フロントエンドは TypeScript を使用（Next.js 可）
- 設計書（ER図・API仕様書・README）を作成・管理すること
- セキュリティ対策（XSS・SQL injection）を実施すること
- 単体テスト・統合テストを作成すること
- ログ：デバッグログは本番環境で出力しないこと

---

## 5. 機能要件

### 認証・ユーザー管理

| 機能               | 概要                                                         |
| ------------------ | ------------------------------------------------------------ |
| 会員登録・ログイン | メール＋パスワード認証。JWT またはセッション管理             |
| ロール管理         | 一般ユーザー／管理者。管理者はレシピ削除・ユーザー管理が可能 |
| プロフィール編集   | 名前・アイコン・自己紹介の更新                               |

### レシピ管理（CRUD）

| 機能                   | 概要                                                             |
| ---------------------- | ---------------------------------------------------------------- |
| レシピ投稿・編集・削除 | タイトル・材料・手順・調理時間・写真。自分の投稿のみ編集・削除可 |
| レシピ詳細・一覧表示   | 全体公開 / 自分だけの公開設定                                    |
| カテゴリ・タグ付け     | 和食・洋食・スイーツなど。複数タグ対応                           |
| 検索・フィルター       | キーワード・材料・カテゴリで絞り込み                             |
| 画像アップロード       | MinIO（S3互換）またはローカルボリュームに保存                    |

### ソーシャル機能

| 機能                 | 概要                                       |
| -------------------- | ------------------------------------------ |
| お気に入り（いいね） | レシピをブックマーク。マイページで一覧表示 |
| コメント投稿         | 「作ってみた！」レポートやアレンジを共有   |

### 管理機能

| 機能                 | 概要                                 |
| -------------------- | ------------------------------------ |
| 管理者ダッシュボード | 不適切コンテンツの削除・ユーザー管理 |

## 6. 認可ルール

| ユーザー種別     | 許可される操作                   |
| ---------------- | -------------------------------- |
| 未ログイン       | レシピ一覧・詳細の閲覧のみ       |
| ログインユーザー | レシピ投稿・お気に入り・コメント |
| 投稿者本人       | 自分のレシピの編集・削除         |
| 管理者           | 全レシピ削除・ユーザー管理       |

---

## 7. API設計

### 認証

| メソッド | パス             | 説明                   |
| -------- | ---------------- | ---------------------- |
| POST     | `/auth/register` | 新規ユーザー登録       |
| POST     | `/auth/login`    | ログイン（JWT発行）    |
| GET      | `/auth/me`       | 自分のユーザー情報取得 |

### レシピ

| メソッド | パス            | 説明           |
| -------- | --------------- | -------------- |
| GET      | `/recipes`      | レシピ一覧取得 |
| GET      | `/recipes/{id}` | レシピ詳細取得 |
| POST     | `/recipes`      | レシピ新規投稿 |
| PUT      | `/recipes/{id}` | レシピ更新     |
| DELETE   | `/recipes/{id}` | レシピ削除     |

## 8. DB設計（概要）

### users テーブル

| カラム        | 型         | 説明                     |
| ------------- | ---------- | ------------------------ |
| id            | UUID / int | 主キー                   |
| name          | string     | ユーザー名               |
| email         | string     | メールアドレス（unique） |
| password_hash | string     | ハッシュ化パスワード     |
| role          | enum       | `user` / `admin`         |
| created_at    | timestamp  | 作成日時                 |

### recipes テーブル

| カラム       | 型          | 説明           |
| ------------ | ----------- | -------------- |
| id           | UUID / int  | 主キー         |
| title        | string      | レシピタイトル |
| ingredients  | text / json | 材料           |
| instructions | text        | 手順           |
| user_id      | FK → users  | 投稿者         |
| created_at   | timestamp   | 作成日時       |
| updated_at   | timestamp   | 更新日時       |

## 10. Git運用ルール

**ブランチ戦略**

```
main
└── develop
    ├── feature/frontend-pages
    ├── feature/backend-recipes
    ├── feature/auth
    └── feature/docker
```

**フロー**

1. `develop` から `feature/*` ブランチを切る
2. 作業・コミット
3. Pull Request を作成
4. チームメンバー1人がレビュー
5. 確認後 `develop` にマージ
