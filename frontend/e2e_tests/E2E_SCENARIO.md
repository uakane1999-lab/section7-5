## テスト実行前の準備
 
```bash

docker compose up -d
 
# 2. マイグレーション実行

# 3. テストデータ投入
docker compose exec backend python seed.py
 
# 4. フロントエンドの起動確認
```

### IT-001 新規ユーザー登録
 
**前提条件**
- 未登録のメールアドレスを用意している
**手順**
 
| # | 操作 | 期待結果 |
|---|------|---------|
| 1 | トップページを開く（http://localhost:3000） | トップページが表示される |
| 2 | 「新規登録」ボタンをクリックする | 新規登録画面に遷移する |
| 3 | ユーザー名・メールアドレス・パスワードを入力する | 各フィールドに入力できる |
| 4 | 「登録する」ボタンをクリックする | ログイン画面またはマイページに遷移する |
| 5 | 登録したメールアドレスでログインできることを確認する | ログイン成功 |
 
**異常系**
 
| # | 操作 | 期待結果 |
|---|------|---------|
| 1 | 登録済みのメールアドレスで登録する | 「このメールアドレスはすでに登録されています」エラーが表示される |
| 2 | 必須項目を空にして登録する | バリデーションエラーが表示される |

### IT-005 レシピ投稿（画像あり）
 
**前提条件**
- ログイン済みであること
- アップロード用の画像ファイル（JPEG・PNG）を用意している
**手順**
 
| # | 操作 | 期待結果 |
|---|------|---------|
| 1 | 「レシピを投稿する」ボタンをクリックする | レシピ投稿画面に遷移する |
| 2 | タイトルを入力する | 入力できる |
| 3 | 材料を入力する | 入力できる |
| 4 | 手順を入力する | 入力できる |
| 5 | 画像ファイルを選択してアップロードする | プレビューが表示される |
| 6 | 「投稿する」ボタンをクリックする | レシピ詳細画面に遷移する |
| 7 | 投稿した内容・画像が表示されることを確認する | 入力した内容・画像が表示される |
| 8 | レシピ一覧に追加されていることを確認する | 一覧に表示される |
 
**異常系**
 
| # | 操作 | 期待結果 |
|---|------|---------|
| 1 | タイトルを空にして投稿する | バリデーションエラーが表示される |
| 2 | 5MB超の画像をアップロードする | 「5MB以下の画像を選択してください」エラーが表示される |
| 3 | PDF等の非対応ファイルをアップロードする | 「JPEG・PNG・WebP形式のみ」エラーが表示される |

### IT-010 他人のレシピは編集・削除できない
 
**前提条件**
- ユーザーAとユーザーBの2アカウントが存在する
- ユーザーAが投稿したレシピが存在する
**手順**
 
| # | 操作 | 期待結果 |
|---|------|---------|
| 1 | ユーザーBでログインする | ログイン成功 |
| 2 | ユーザーAのレシピ詳細画面を開く | 編集・削除ボタンが表示されない |
| 3 | 直接APIを叩いてPUT /recipes/{id}を実行する | 403 Forbidden が返る |
| 4 | 直接APIを叩いてDELETE /recipes/{id}を実行する | 403 Forbidden が返る |
 
---
 
### IT-011 未ログインでの操作制限
 
**前提条件**
- ログアウト状態であること
**手順**
 
| # | 操作 | 期待結果 |
|---|------|---------|
| 1 | レシピ一覧画面を開く | 一覧が表示される（閲覧は可能） |
| 2 | レシピ詳細画面を開く | 詳細が表示される（閲覧は可能） |
| 3 | レシピ投稿画面に直接アクセスする | ログイン画面にリダイレクトされる |
| 4 | 直接APIを叩いてPOST /recipesを実行する | 401 Unauthorized が返る |
| 5 | 直接APIを叩いてGET /users/meを実行する | 401 Unauthorized が返る |
